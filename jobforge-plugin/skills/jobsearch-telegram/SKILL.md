# Job Search Telegram Polling

Poll Telegram for incoming messages and route them to JobForge skills headlessly.

## Commands Supported via Telegram
- Send job URL → Scans form, prepares tailored resume, asks for confirmation to apply
- `search [keywords]` → Searches matching jobs
- `tailor resume for [job]` → Optimizes resume
- `status` → Application pipeline tracker
